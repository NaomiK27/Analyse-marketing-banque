# Analyse-marketing-banque
## Objectif
Ce projet porte sur l’analyse des données issues  d’une campagne marketing bancaire visant à proposer un dépôt à terme à ses clients.

## Dataset 
Le dataset contient des information sur :
- l'age des prospects
- la profession
- le statut marital
- les variables relatives à la campagne marketing
- le taux de résultat de la campagne

## Outils utilisés
- Python : Pandas, seaborn, matplotlib
- Data visualization : Power BI

## Analyses réalisées
- Exploration des données
- Nettoyage des données
- Visualisation et intérprétation des résultats
